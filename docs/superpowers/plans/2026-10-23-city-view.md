# City View Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every city an isometric grid on which its houses stand, a city view scene where the player places houses and workshops from a build bar, an Editor tool to design a city's grid, and placement strategies that place the city's own houses.

**Architecture:** The grid, footprints, placement rules and strategies are plain C# in `Core/CityView`, and `CityMarket` builds its houses through its grid when it has one (no grid = today's behaviour, so every existing test stays valid). Each city's grid is a `CityLayoutDefinition` asset referenced by its `CityDefinition`; the strategy is a `PlacementStrategyDefinition` asset referenced by the buildings catalogue. The city view is a scene of its own, `CityView.unity`, loaded additively over `WorldMap.unity` by a `CityViewLoader` that switches the map's camera and input off while it is open; the view reaches the simulation through `SimulationServices.Current`.

**Tech Stack:** Unity 6000.6.4f1, C#, URP 2D Renderer, UI Toolkit, new Input System, NUnit EditMode tests (run with the `run-tests` skill).

**Spec:** `docs/superpowers/specs/2026-10-23-city-view-design.md` (mockups in `docs/superpowers/specs/2026-10-23-city-view-mockups/`).

## Global Constraints

- New subsystem `CityView`: subfolders `Assets/Scripts/Core/CityView`, `Assets/Scripts/Game/CityView`, `Assets/Scripts/Editor/CityView`, `Assets/Tests/EditMode/CityView`, and a rule `.claude/rules/city-view.md` whose `paths` match them (Task 2 creates it; later tasks add to it what cannot be read from the code).
- All code, comments, asset and folder names in English; everything the player reads in French. Never name the game the project is inspired by, anywhere.
- Every list the player reads is sorted with `NameOrder`; rows of a list are striped with `ListStripes.Apply` (the build bar's buttons are one horizontal row of items, not rows: not striped).
- A good's name never carries its unit in parentheses.
- Materials of a construction go through `BuildingDefinition.MaterialsOf` (switched-off materials left out).
- ScriptableObjects hold static definitions only; the runtime grid (`CityGrid`) is never written back into a `CityLayoutDefinition` at runtime.
- Every runtime `UIDocument` uses the one game `PanelSettings` (`Assets/UI/WorldMap/WorldMapPanelSettings.asset`).
- Every new scene object, asset and reference is created by the scene setup (`Tools > Dark Fantasy Merchant > Build World Map Scene`), leaving what exists untouched.
- Only the new Input System; the city view gets its own action map `CityView` in `Assets/InputSystem_Actions.inputactions`.
- Footprints: every house **2×1**, every workshop **2×2** (data on the building assets, set by the setup).
- Default grid: **40×40** cells, no forbidden cell (Claude's call).
- Colours (placeholder, Claude's call): player's buildings blue `#3D5F9B`, city's brown `#7A5A3A`, free cell `#3B4A3A`, forbidden cell `#24435E`, ghost valid green `#6FBF73` and invalid red `#D05050`, both at 60 % alpha.
- Commit at the end of every task, on `main`, message in French in the repository's style (`Sous-système : ce qui change`). No push.

## Review Focus

1. **A full grid** — the city keeps getting crowded but no 2×1 place is left: no house, no room, no material taken, every day, without exception or log spam. Test in Task 4 (`BuildCityHouses_BuildsNothing_WhenTheGridHasNoPlace`).
2. **Room and grid drifting apart** — after any mix of starting houses, city houses and player houses, each class's room equals its houses on the grid × the room of a house of the class. Test in Task 4 (`Room_IsAlwaysTheHousesOnTheGrid`).
3. **A footprint at the edge or over a forbidden cell** — a 2×1 turned across at the last column, a 2×2 overlapping one forbidden cell or one cell of another building: refused by `CanPlace`, by the player's build and by the strategy. Tests in Task 2 (`CanPlace_RefusesAFootprintThatLeavesTheGrid`, `CanPlace_RefusesOneForbiddenOrTakenCell`).
4. **Paying for a building that cannot stand** — the player clicks a place that became taken between the hover and the click (the city built there the same frame): nothing is paid. Test in Task 4 (`TryBuildHouse_TakesNothing_WhenThePlaceIsTaken`).
5. **Map input leaking through the city view** — a click, wheel step or right click in the city view selects, zooms or orders nothing on the map; leaving the view gives the map back exactly as it was. Checked in play mode in Task 10, Step 6.

```csharp
namespace DarkFantasyMerchant.Core
public enum BuildingOrientation { Along, Across }           // Along: Width on x, Depth on y; Across: swapped
public readonly struct Footprint {                          // Width, Depth >= 1, else ArgumentOutOfRangeException
    public Footprint(int width, int depth);
    public int Width { get; } public int Depth { get; }
    public bool IsSquare { get; }
    public Vector2Int SizeFor(BuildingOrientation orientation);
}
public enum BuildingOwner { City, Player }
public readonly struct BuildingKind {
    public static BuildingKind House(SocialClass housedClass);
    public static BuildingKind Workshop(int good);
    public bool IsHouse { get; } public SocialClass HousedClass { get; } public int Good { get; }
}
public readonly struct GridPlace {                          // Origin = the covered cell of smallest x and y
    public GridPlace(Vector2Int origin, BuildingOrientation orientation);
    public Vector2Int Origin { get; } public BuildingOrientation Orientation { get; }
}
public sealed class PlacedBuilding {
    public BuildingKind Kind { get; } public BuildingOwner Owner { get; }
    public Footprint Footprint { get; } public GridPlace Place { get; }
    public Vector2Int Size { get; }                         // Footprint.SizeFor(Place.Orientation)
}
public sealed class CityGrid {
    public CityGrid(int width, int height, IEnumerable<Vector2Int> forbidden); // size >= 1; a forbidden cell outside: ArgumentOutOfRangeException
    public int Width { get; } public int Height { get; }
    public bool Contains(Vector2Int cell);
    public bool IsForbidden(Vector2Int cell);
    public PlacedBuilding BuildingAt(Vector2Int cell);      // null when free or outside
    public IReadOnlyList<PlacedBuilding> Buildings { get; } // in the order they were placed
    public bool CanPlace(Footprint footprint, GridPlace place);
    public PlacedBuilding Place(BuildingKind kind, BuildingOwner owner, Footprint footprint, GridPlace place); // InvalidOperationException when !CanPlace
    public void GetPlaces(Footprint footprint, List<GridPlace> results); // clears results; every place that fits, x then y, Along before Across; a square footprint only Along
    public int HousesOf(SocialClass housedClass);           // city's and player's
    public event Action<PlacedBuilding> BuildingPlaced;
}
```
