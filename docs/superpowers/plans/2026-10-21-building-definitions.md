# Building definitions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every building the player can build becomes its own ScriptableObject (name, gold, materials; a workshop adds its good and jobs, a house its class and room), listed by the `BuildingsDefinition` catalogue, with the cost shown on hover of the "Construire" button.

**Architecture:** Game gets an abstract `BuildingDefinition` and two subclasses, which carry their own cost helpers. `BuildingsDefinition` becomes a catalogue of them and turns them into plain "offers" (name, cost, cost text, jobs or room) that `WorldEconomy` exposes and `CityBuildingsSection` shows. Core does not change.

**Tech Stack:** Unity 6000.6.4f1, C#, UI Toolkit, NUnit EditMode tests (run with the `run-tests` skill).

**Spec:** `docs/superpowers/specs/2026-10-21-building-definitions-design.md`

## Global Constraints

- All code, comments, asset and folder names in English; everything the player reads in French; numbers through `TreasuryHudController.FormatNumber` / `FormatGold`.
- Every list the player reads is sorted with `NameOrder`.
- ScriptableObjects hold static data only.
- Materials always go through `MaterialsOf`: an inactive material is left out and never makes a building unavailable.
- `WorldMapSetup.Build` creates every new data asset and reference, and leaves what exists untouched.
- Assets are created, moved and deleted with their `.meta`.
- Nothing in the repository names the game this one is inspired by.
- Commit on `main` at the end of each task, message in French like the recent ones (`Bâtiments : …`), no push.

## Review Focus

- **A workshop whose good is switched off** (not an active good): it gives no offer and no row, and nothing throws. Test in Task 2 (`CreateWorkshopOffers_SkipsAWorkshopOfAnInactiveGood`).
- **Running the setup twice, or on the migrated catalogue**: no definition is duplicated in the catalogue. Test in Task 2 (content test counts 3 houses, 20 workshops).
- **A city that produces a good without a workshop definition**: no row for it, the others still show. Test in Task 2 (`AGoodWithoutAWorkshop_HasNoRow`).
- **Hovering a disabled button** (no gold, missing materials, unavailable cost): the tip still shows the full cost, or "indisponible". Test in Task 3 (`TheCostTip_ShowsForADisabledButton_AndUnavailableForABuildingWithoutCost`).
- **The tip left on screen** when the section hides or shows another city while the pointer is on a button. Test in Task 3 (`HideAndShow_HideTheCostTip`).
